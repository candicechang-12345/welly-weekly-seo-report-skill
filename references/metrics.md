# 數字口徑摘要

數字都由程式算，這份只在要核對或解釋時讀。設定寫在 `scripts/metrics.py`（BRANDS）與 `scripts/weekly_plan.py`。

## 品牌、頻率與資源

| 程式用的品牌名 | 網站 | 頻率 | GSC 資源 | GSC 國家 | GA4 資源 ID |
|---|---|---|---|---|---|
| Welly | welly.tw（舊站） | 每週 | `sc-domain:welly.tw` | 台灣（twn） | 309886039 |
| WellyNew | wellyblog.tw（新站） | 每週 | `https://wellyblog.tw/`（網址前置字元資源，不是 sc-domain） | 台灣（twn） | 562289258 |

GSC 一定要套國家篩選，沒套數字會對不上過去的報告。

## 期間

- **報告週**：上週一到上週日，比較再前一週。
- **月報週判斷**：報告週包含某月最後一天，這週就加做那個月的 WellyHK、Haveababy 月報（本月整月 vs 上月整月）。例：8/31–9/6 做 8 月；9/21–9/27 不做；10/26–11/1 做 10 月。以 `python weekly_plan.py` 的輸出為準，不要自己算。
- **月累（本月累積非付費流量）**：
  - 週報品牌：本月 1 號到報告週週日，比較上月 1 號到上月同一天。
  - 月報品牌：本月整月比上月整月。
- 程式拒絕 2026-10-26 以前的報告週，那之前是同事手填的資料。

## GA4 四格

| 項目 | 算法 |
|---|---|
| 總工作階段 | 全部來源的工作階段加總 |
| 自然流量工作階段 | 工作階段媒介是 organic、(none)、referral、(not set) 這四種的加總 |
| 自然流量平均參與時間 | 上面四種媒介各自的平均工作階段時間，直接平均（不加權），寫成 mm:ss |
| 自然流量跳出率 | 上面四種媒介各自的跳出率，直接平均（不加權） |

月累＝GA4 逐日「全部」工作階段加總。欄位名稱寫「非付費」，但沿用舊表的口徑沒有排除付費，不要自行修正。某天沒資料時程式會印「WARNING GA4 缺資料日期」，過幾小時重跑（新站流量小，整天 0 不算缺資料）。

和舊試算表的數字有落差屬於預期：舊公式寫死列號，有幾週抓錯列。

## GSC 四項

點擊量、曝光量、平均點閱率、平均排序，來自 Search Console API 整站加總（套國家）。

Welly 大字「SEO」「SEO公司」：
- 舊站用「查詢＋頁、完全相符」的主攻頁數據：SEO → `/blog/what-is-seo`，SEO公司 → `/blog/how-to-choose-seo-agency`。
- 新站只篩查詢（完全相符），不篩頁。
- 排名變化＝兩期平均排名各自四捨五入到小數 1 位再相減。

## API 拿不到、要從介面讀的項目

| 項目 | 來源 | 寫法 |
|---|---|---|
| 良好網站比例 | GSC 網站使用體驗核心指標 | 良好／行動裝置需優化／桌面需優化／需優化／資料不足 |
| GSC外鏈數量 | GSC 連結 → 外部連結「連結總數」 | 數字 |
| GSC外鏈域名 | GSC 最常連結的網站 → 頁面底部「共 N 列」 | 數字（最多顯示 1000，照實填） |
| DR、UR | Ahrefs API（`ahrefs_api.py`），不行再用 Ahrefs 網頁 | 數字；UR 是首頁 UR |

上期的這些項目，程式會讀上週報告文件裡那張表。

## 無痕排名寫法

- 第 1 頁：「無痕第 N 名」。
- 其他頁：「無痕第二頁」「無痕第三頁」（國字）。
- 前五頁都沒有：「沒有出現在無痕前五頁」。
- Haveababy 另有「掉出無痕首頁」。
- 查詢網址固定帶 `hl=zh-TW&gl=tw&pws=0`。

## 執行紀錄

雲端硬碟交接資料夾裡的「週報執行紀錄」試算表，一週一列：週次、狀態（填表中／已完成／未完成）、電腦、負責人、開始、結束、報告文件、回報。「填表中」超過 3 小時視為上次中斷，可以重跑。
