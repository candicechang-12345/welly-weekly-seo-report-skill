# welly-weekly-seo-report（Claude 技能）

Welly 每週內部 SEO 數據報告的 Claude 技能。正式版本在 Skillport；這個 repo 是備份，Skillport 裝不起來時用。

版本：1.1.2（2026-11-27 從 Skillport 同步）

## 安裝

把整個 repo 放到 `%USERPROFILE%\.claude\skills\welly-weekly-seo-report\`（資料夾裡直接就是 `SKILL.md`），重開 Claude 桌面版。
然後在 Claude 說「從頭完成每週數據報告的第一次設定」。

金鑰（`client_secret.json`、`ahrefs.env`、`dataforseo.env`）不在這裡，從雲端硬碟金鑰資料夾拿。
